## Patch-Hinweis (ZIP-Workflow)

Bei Patch-ZIPs immer:
1. ZIP ins Projektroot legen
2. entpacken
3. ZIP direkt wieder löschen
4. Patch anwenden
5. `npm run typecheck`, `npm run lint:ci`, `npm run test:silent`
6. erst dann commit + push
