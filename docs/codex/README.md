# Codex (Deutsch)

Hier liegt der Copy/Paste Startprompt für einen Codex Cloud Agent.

- Prompt: `docs/codex/PROMPT_DE.md`

**Tipp:** Wenn du dem Agenten eine Aufgabe gibst, pack die relevanten Dateien/Ordner dazu (z.B. `screens/`, `lib/diagnostics/`, `supabase/`), und sag klar:
- *Was soll raus?*
- *Was soll rein?*
- *Was ist “fertig”?* (z.B. Tests grün, UI ok, weniger Dateien etc.)
