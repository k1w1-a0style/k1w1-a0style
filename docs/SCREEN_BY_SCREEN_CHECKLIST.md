# Screen-für-Screen Abgleich (Checklist)

Ziel: Einmal alles sauber klären, damit die App stabil bleibt und sich nichts „aus Versehen“ wieder verdreht.

Pro Screen beantworten wir nur diese Punkte (einfach, ohne Fachchinesisch):
1. **Wozu ist der Screen da?**
2. **Was liest er?** (welche Auswahl/Daten nutzt er)
3. **Was schreibt er?** (was speichert/ändert er)
4. **Buttons / Aktionen** (was darf man drücken, was passiert)
5. **Fehlerfälle** (was kann schief gehen, welche Meldung soll kommen)
6. **Niemals-Regeln** (z.B. Repo/Branch nicht überschreiben)

## Reihenfolge (damit’s schnell Sinn ergibt)
1) Connections
2) GitHub Repos
3) Diagnostic
4) Build
5) Status / CI Lite
6) Chat
7) Code
8) Terminal
9) Preview
10) Credentials Wizard
11) Settings
12) App Info
